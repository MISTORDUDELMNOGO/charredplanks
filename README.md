# Инструментальные средства разработки программного обеспечения

Название команды: Сталкеры

Участники проекта: Фишман Д.Р., Бурханов А.А., Торохов М.А.

Цель: Разработка декоративного блока «Обугленные доски» (Charred Planks) в Minecraft (Fabric, версия 1.21).
📖 Описание

Мод добавляет в игру декоративный блок «Обугленные доски». Блок не имеет сложных механик, предназначен для строительства и декора. При клике правой кнопкой мыши по блоку в чате появляется сообщение «Тепло от угля».
🛠️ Совместимость
Компонент	Версия
Minecraft	1.21
Fabric Loader	0.19.5 или новее
Fabric API	0.102.0+1.21
Java	21
📦 Установка

    Установите Fabric Loader для Minecraft 1.21.

    Скачайте Fabric API (версия 0.102.0+1.21) и файл charredplanks-1.0.0.jar.

    Положите оба JAR-файла в папку mods вашей игры.

    Запустите Minecraft с профилем Fabric 1.21.

    Найдите блок во вкладке «Строительные блоки» в творческом режиме или скрафтите его.

🧱 Рецепт крафта

Бесформенный рецепт (порядок не важен):

    1 обычная доска (любая)

    1 уголь (любой)

Результат: 1 блок «Обугленные доски».
🎮 Использование

    Блок можно ставить в мире как обычный декоративный блок.

    Блок выпадает при разрушении рукой или любым инструментом.

    При клике правой кнопкой мыши по блоку в чате появляется сообщение «Тепло от угля».
